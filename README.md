# Meu Chat

Aplicativo de mensagens desenvolvido em React Native com Expo para uma atividade acadêmica da UFC.

O projeto simula conversas entre quatro contatos fictícios, com envio de mensagens e armazenamento em memória.

## Funcionalidades

- Lista de contatos
- Navegação entre conversas
- Envio de mensagens
- Conversas separadas por contato
- Validação de mensagens vazias

## Tecnologias

- React Native
- Expo
- JavaScript
- React Navigation

## Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd ufc-chat
```

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npx expo start
```

Abra o aplicativo pelo Expo Go, utilizando o QR Code exibido no terminal.

## Sobre

Projeto acadêmico desenvolvido para a Universidade Federal do Ceará (UFC), Campus Quixadá.
